# Welcome to Crowell Digital Marketplace-Claude CRM

## Overview

**crowell digitall marketpace - claude CRM** (`https://claude.scraperscraper.com`) is a lead pipeline, employment/contract tracking, and outreach CRM supporting **ZapAI**, **Newton Health**, and **KinematicOps**.

### Key Routes

- `/` (`/dashboard`) — Kanban Lead Pipeline Board (`PipelineBoard`)
- `/leads` — Filterable Leads Table & Lead Detail Drawer (brand, job type, stage, priority, play, and employment details)
- `/outreach` — Outreach Draft Generation & Status Tracking (`Draft`, `Approved`, `Sent`, `Bounced`)

## Built with

- TanStack Start & TanStack Router
- TypeScript
- React 19
- Tailwind CSS v4
- Supabase & Drizzle ORM
